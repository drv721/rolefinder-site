# Role Finder — hosted dashboard + iPhone push

This repo is the publishable half of the Role Finder job dashboard. It auto-deploys
to Cloudflare Pages on every push to `main` (like your other sites), and its
`functions/` folder is the push hub that sends iPhone notifications after each scan.

The private halves (VAPID key, notify token) NEVER live here — they are Cloudflare
secrets set in the dashboard, and a local file on your laptop.

## What's inside

| File | What it does |
|---|---|
| `index.html` | The dashboard (regenerated by `scan.py`, copied here by `sync_site.py`) |
| `data/latest.json` | Latest scan results (the service worker reads this to build the notification) |
| `manifest.webmanifest` | Makes the site installable (home-screen app) |
| `sw.js` | Service worker: receives pushes, shows the notification, opens the dashboard on tap |
| `icons/` | App icons |
| `functions/subscribe.js` | POST `/subscribe` — saves your phone as a subscriber (KV) |
| `functions/notify.js` | POST `/notify` — sends the push to all subscribers (VAPID-signed) |

## One-time setup — do these in order (~10 minutes, all in your browser)

### 1. GitHub → Cloudflare Pages (the site)
1. On cloudflare.com: **Workers & Pages → Create → Pages → Connect to Git**.
2. Pick the **rolefinder-site** repo → **Begin setup**.
3. Leave defaults → **Deploy**. Wait for the green checkmark.
4. Your site URL is now **https://rolefinder.pages.dev** (shown on the project page).

### 2. Create the KV storage (for the subscriber list)
1. Cloudflare dashboard → **Workers & Pages → KV** → **Create a namespace**.
2. Name it exactly: `rolefinder-subs` → **Add**.
3. Copy the **ID** shown (it starts with a long hex string). Not strictly needed for
   the next step, but handy.

### 3. Wire the three bindings (this is where the magic connects)
1. Go to **Workers & Pages → your rolefinder project → Settings → Functions**.
2. Under **KV namespace bindings** → **Add binding**:
   - Variable name: `SUBS`
   - KV namespace: `rolefinder-subs`
   - Save.
3. Under **Environment variables**, add TWO **secret** (encrypted) variables:
   - `VAPID_PRIVATE_KEY` — paste the entire contents of the file
     `vapid.jwk.json` (it's the JSON object, starting with `{`)
   - `NOTIFY_TOKEN` — paste the token from your laptop's
     `work/rolefinder/pwa-config.json` (the `notify_token` value)
4. Save, then **Redeploy** (Deployments → three dots → Retry deployment) so the
   new settings take effect.

### 4. Turn on the phone
1. On your iPhone, open **Safari** → go to **https://rolefinder.pages.dev**.
2. Tap **Share** (square-with-arrow) → **Add to Home Screen** → **Add**.
3. Open the **Role Finder** app from your home screen.
4. Tap **Enable notifications on this device** → **Allow**.
5. You'll see "✓ Alerts enabled on this device." Done.

## How the loop runs after that
- The laptop's scheduled scans (7 AM / 3 PM) run `scan.py`, then `sync_site.py`.
- `sync_site.py` copies the fresh dashboard here, pushes to `main` → Pages
  auto-redeploys the site.
- If new roles were found, it also calls `/notify` → your phone buzzes with the
  count and the top titles → tap it, dashboard opens.

## Troubleshooting
- **No notification after a scan with new roles:** open the push hub URL
  `https://rolefinder.pages.dev/notify` in a browser — it should say "push hub is up".
- **"Enable failed (401)":** check the `SUBS` binding name is exactly `SUBS`.
- **"Enable failed (500)":** check `VAPID_PRIVATE_KEY` is the full JSON (starts `{`).
- **Phone never asks permission:** make sure you opened the site from the home
  screen (installed), not Safari tabs; check Settings → Safari → Notifications.
