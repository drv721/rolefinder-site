How this works & limits

Scans: LinkedIn guest search (Chicago + remote-US, past 7 days, no login needed) · ATS APIs (Greenhouse/Lever/Ashby via token discovery) · remote job feeds (Remotive) · web search (Bing RSS) · best-effort career-page scans for Workday/other ATS companies. Job boards that block automated access (Indeed, Workday-embedded pages, some Greenhouse boards) are not fully covered — treat this as a signal layer, not the complete universe. "Posted last 24h" uses each feed's own timestamp when available, else the first time the role was seen by a scan. To tailor a resume for a role, tell V in chat ("tailor resume for [role]") — done in a fresh session (v4-pro). Applications you mark below are tracked locally and synced to the job-search repo on request.
